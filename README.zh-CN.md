# Hop 中文版

Hop 是一个类似 AirDrop 的桌面文件互传工具，面向同一局域网内的 Mac 和 Windows 电脑。此仓库 fork 自 [0xCodez/hop](https://github.com/0xCodez/hop)，保留 MIT 许可和原作者信息。

## 中文界面

桌面端根据系统语言自动选择简体中文或英文；所有 `zh` 系统语言当前统一使用简体中文，其他语言回退英文。覆盖设备发现、拖放提示、收发进度、接收确认、信任设备、保存目录、外观辅助标签、Windows 托盘、原生文件选择框标题及通知。系统文件选择框的系统按钮由操作系统决定语言，底层网络和系统错误保留原始诊断信息。

可以通过环境变量覆盖语言，完全退出旧进程后重新启动：

```bash
HOP_LANG=zh-CN npm start
HOP_LANG=en npm start
```

Windows PowerShell：`$env:HOP_LANG='zh-CN'; npm start`。

翻译集中在 `src/shared/i18n.js`，由主进程和沙箱内的页面共享；设备 ID、网络协议和文件路径不参与翻译。网站 `site/` 和演示数据保留上游英文，不影响桌面端中文收发。

## 能做什么

- **自动发现设备**：同一 Wi-Fi 或有线局域网，双方启动 Hop 后自动显示，无需账号和云端服务。
- **发送文件和文件夹**：拖到目标设备；也可点击设备选择文件。macOS 选择框可同时选文件和目录；Windows 选择框只选文件，文件夹用拖放发送。
- **确认接收**：接收方选择接收或拒绝。可信任自己的设备，以后自动接收，也可清除全部信任。
- **传输反馈**：显示等待状态和百分比；点击正在发送的设备可以取消发送。
- **管理收到的文件**：默认保存到 `Downloads/Hop`，可以更改目录并打开位置；同名文件自动增加序号，避免覆盖。
- **后台接收**：关闭窗口仍保留进程，Windows 使用托盘、macOS 使用 Dock；需要彻底退出时退出应用。
- **个性化**：重命名本机，切换浅色、深色或跟随系统外观。

## 适用场景与边界

适合个人 Mac 和 Windows 之间交换照片、视频、项目素材，以及家庭或可信办公室内临时传文件。这里的 AirDrop 风格指交互方式；它不是 Apple AirDrop 协议，也不能直接接收 iPhone 的 AirDrop。

当前没有手机端、互联网中继、账号系统、同步目录、断点续传或端到端加密。发现依赖 UDP 广播（端口 47800），文件通过 HTTP 流式直传；访客网络隔离、VPN、防火墙或跨网段可能阻止发现。Windows 防火墙需允许专用网络访问，macOS 需允许本地网络访问。

传输内容没有加密，设备信任基于对方声明的设备 ID，不是密码学身份认证；因此只应在可信网络使用，不能把“信任设备”当成强认证。协议每次接收清单最多 50,000 项，清单请求体上限 8 MiB，等待用户确认约 60 秒；这些不是无限大目录传输的保证。

如果要演进成更通用的产品，优先补充配对认证和加密，再考虑断点续传、手动 IP 连接、移动端及自动同步；这些能力当前尚未实现。

## 开发与验证

需要 Node.js 22+：

```bash
npm ci
npm test
npm start
npm run dist:mac
npm run dist:win
```

`npm test` 包含语言选择、插值、英文回退及浏览器沙箱导出测试，以及 UDP 发现、文件和目录传输、同名避让、拒收的网络冒烟测试。

上游提供 macOS Apple Silicon/Intel 与 Windows x64 的构建配置。此 fork 的中文安装包尚未发布；上游发布页下载的是上游版本。macOS 上游安装包目前未公证，安装与首次运行说明参见英文 README。实际跨机、Windows 原生菜单和安装包签名需在目标设备验证。
